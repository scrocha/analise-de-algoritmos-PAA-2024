# Projeto e Análise de Algoritmos

Repositório de implementações em C++ e listas de exercícios da disciplina de Projeto e Análise de Algoritmos.

## Conteúdo

| Lista | Tópicos e arquivos |
|---|---|
| [A1 — enunciado](<./listas/PAA A1 2024 Lista Exercícios.pdf>) | Ordenação e seleção, heaps, árvores de busca binária; implementação em [`main_A1.cpp`](./implementacoes/main_A1.cpp). |
| [A2 — enunciado](<./listas/PAA A2 2024 Lista Exercícios.pdf>) | Percursos em grafos, busca em largura e profundidade, caminhos mínimos e árvore geradora mínima; implementação em [`main_A2.cpp`](./implementacoes/main_A2.cpp), com estruturas em [`structs.hpp`](./implementacoes/structs.hpp). |

## Como compilar

Compile e execute cada lista separadamente, a partir da raiz do repositório:

```bash
g++ -std=c++11 implementacoes/main_A1.cpp -o main_A1
./main_A1

g++ -std=c++11 implementacoes/main_A2.cpp -o main_A2
./main_A2
```
